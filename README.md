Travel Budget Planner and Expense Analyzer
A Python-based application that helps users plan travel budgets and compare estimated expenses with actual spending.

Key Features:
- Records destination, trip duration, and budget.
- Tracks estimated and actual expenses for Travel, Food, Hotel, and Others.
- Calculates total expenses, remaining budget, and daily averages.
- Identifies major expense categories and spending differences.
- Provides budget warnings and validates user inputs.
Technologies: Python 3, lists, dictionaries, loops, conditional statements, and exception handling.

Execution: Run python main.py in the terminal.

Outcome: Helps users monitor spending, identify overspending, and manage travel expenses effectively.
